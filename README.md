# PLP-PYTHON-WEEK4
PLP Week 4 Assignment – Hands-On Lab

Files

- welcome.py – Contains a welcome function that returns a greeting message using a person's name.
- toolbox.py – Contains three functions: "double()" to multiply a number by two, "is_pass()" to check whether a score is 50 or above, and "greet()" to create a personalized greeting.

Hardest Function

The hardest function to write was "greet()" because it uses an optional parameter with a default value. Understanding how to combine the greeting and name into one sentence took some practice.
